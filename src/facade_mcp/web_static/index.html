从素材到报告

  1. 填写建筑信息

    提供建筑名称、位置和巡检期次。

  2. 上传真实素材

    支持图片、视频、TXT / Markdown / PDF。视频抽帧后参与检测；PDF 提取文字，不执行 OCR。

  3. 发送报告要求

    系统调用本地检测、分割和报告 MCP。缺少模型或依赖时会说明原因。

  4. 直接编辑或对话修改

    例如：“标题改为A栋复查报告”“第1条改为白华”“第1条处理建议改为现场复核”。更自由的文字改写需要启用已配置的在线助手。

此版本为本机单用户工作区，不提供多人账号、正式签署或 PDF / Word 导出。HTML 可下载后在浏览器打印。
