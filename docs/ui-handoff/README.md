## 交付文件

- `canva-editable.html`：Canva导入源，独立文字与几何布局，不是截图；每页坐标在HTML内。
- `build_canva.py`：重新生成源文件和样式tokens。
- `tokens.json`：颜色、字体、间距、圆角、桌面分栏宽度。
- `layout.json`：5个页面的元素名称、文字、坐标、宽高和样式，便于程序读取。
- `canva-page-1.png` 至 `canva-page-5.png`：Canva导入后的预览核对图。
- `../../src/facade_mcp/web_static/`：真实HTML/CSS/JavaScript实现。
- `../../src/facade_mcp/web_app.py`：API、MCP调用、持久化与版本管理。
- [功能和接口说明](../web-app.md)：输入输出、范围、启动、验收说明。

## 交互与验收约定

上传素材不自动启动付费模型。发送指令后进入可见运行状态，保留输入素材并阻止重复执行；失败显示原因。新报告进入编辑区。直接编辑和提示词修改都生成版本；导出前先等待保存。不可编辑的证据和像素面积与人工文字区分显示。

蓝色为主操作和选中状态；不使用绿色。报告文字有焦点边框和编辑工具栏，确保一眼能看出可编辑。设置为按需弹出面板，避免常驻多级导航。原UI、原PRD与本交付并存，本目录不覆盖旧稿。

设计文案里的示例建筑、文件名、缺陷和版本均为示例，不是检测事实。Canva用于设计协作；可运行行为以代码和功能说明为准。
